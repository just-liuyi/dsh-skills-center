# @local/dsh-skills-center · 技能中心

左侧栏统一管理 **Skill、MCP 服务器、提示词注入与 Tools**。本地与在线技能展示在同一个 Skill 页中，以来源分组和标签区分；所有新添加技能默认停用，由用户手动开启。

## Skill 管理

### 本地安装与在线安装

- **本地技能分组**：展示用户目录、当前项目、内置与插件提供的技能。没有来源记录的旧技能仍归在这里，不根据名称猜测其来源。
- **在线来源分组**：按仓库来源展示已经添加的技能，每个技能独立启停。尚未安装的来源条目留在添加预览中，不混入主列表的停用计数。
- 本地与在线不再使用独立子标签；搜索、全部／已启用／已停用筛选和计数覆盖整张 Skill 列表。
- 「在线安装」标题后的「全部展开／全部折叠」统一控制所有已添加的来源；点击各来源标题可单独展开或折叠其技能列表。筛选时仍可操作，隐藏的来源也会同步批量状态，折叠仅影响展示。
- 进入 Skill 页时在线来源默认全部折叠；展开状态在本次查看中保留，新出现的来源同样以折叠状态加入。
- 每个来源的操作区只有文本按钮「刷新来源」与「删除来源」；删除需要二次确认并显示将删除的技能数量。删除后无需重启插件：技能目录变化由宿主文件监听捕获，面板立即刷新，模型下一步也会看到新的技能列表。
- 用户技能可以管理；当前项目、内置与插件技能遵循原有只读限制。

### 添加技能：搜索或从链接添加

在 Skill 页点击「添加技能」，可在同一个面板中选择两种方式：

- **搜索技能**：输入关键词，从 skills.sh 目录获取匹配项，查看名称、来源及安装量，点击「添加」即可加入在线来源分组，无需再次预览勾选。可以在搜索面板中连续添加多个技能。
- **从链接添加**：输入公开 GitHub 仓库、子目录、技能文档地址，或 skills.sh 的技能详情链接；也支持 `owner/repo` 简写。链接方式保留预览和多选；来源分组中也可继续添加该来源的其他技能。

所有全新添加的技能一律停用，模型与用户调用都关闭；需要使用时，在 Skill 列表中手动打开开关。添加流程不再提供「安装后启用」选项。重复添加已有技能不会重装，也不会更改现有开关；显式关联已有本地技能时保留原状态。

技能详情只添加对应技能，不默认安装整个仓库。已有同名但不同来源的技能会明确提示冲突，不静默覆盖或自动关联。

安装时复制完整技能目录，包含引用文档、脚本和模板，不执行仓库中的代码。skills.sh 是目录入口，实际内容仍来自解析后的 GitHub 仓库，后续检查和更新继续跟踪该来源。

目前支持公开 GitHub 来源及 skills.sh 中指向 GitHub 的技能。不把任意网页、npm 包或命令当作技能安装源。仓库里的 MCP 与其他客户端插件配置不随技能一起启用。

### 已有技能与更新

- 添加来源不会直接覆盖本地同名技能。
- 内容一致、位于 `<dshHome>/skills` 的完整技能目录可以显式关联来源；存在差异时保留原文件并显示冲突。通用 Agent 目录中的旧技能暂不支持直接关联。
- 「刷新来源」重新读取上游并更新来源记录，不代表自动更新已安装内容。
- 从详情链接按需导入的来源只检查已解析技能；需要添加其他技能时，继续搜索或解析仓库地址，同仓库仍归入同一来源。
- 更新以完整技能目录为单位。存在本地修改时拒绝直接覆盖，避免丢失自定义内容。
- 每个技能的启停互相独立；更新保留其启停状态。停用后保留安装内容。
- 在线来源托管的技能正文只读，避免普通编辑与上游更新互相覆盖。

## MCP 与提示词

| 标签 | 功能 | 数据位置 |
|---|---|---|
| Skill | 查看、编辑本地用户技能、安装在线技能、来源追踪、启停、更新和卸载 | 用户技能位于 `<dshHome>/skills/<name>/`；来源信息位于 `<dshHome>/dsh-skills-center/sources.json` |
| MCP | 新建、编辑、删除、启停；展示其他插件的服务器 | `dsh-switch-mcp` group，经 `configEditor` 持久化 |
| 提示词 | 新建、编辑、启停、删除，按顺序注入系统提示词 | `<dshHome>/dsh-skills-center/store.json` |
| Tools | 查看宿主提供的工具及参数 | 宿主工具注册表，只读 |

`dshHome` 跟随 `DSH_HOME`，默认 `~/.dsh`。通用 Agent 用户技能目录跟随 `DSH_AGENTS_HOME`，默认 `~/.agents`。

只有 MCP、提示词可在面板里新建空白条目。Skill 通过添加在线来源安装，或由用户、Agent 在磁盘上创建。

快捷键 `/` 聚焦搜索，`N` 打开当前页的添加入口，输入框中不拦截。编辑器支持 `Ctrl + S` 保存和 `Esc` 关闭；多行正文编辑时保留 `Esc`。

### 侧栏防误关闭

技能中心的添加、编辑和详情抽屉不会因点击外部遮罩关闭。顶部退出入口位于抽屉左侧独立操作行，使用带文字的「关闭」按钮，与 DSH 窗口右上角的关闭按钮分开；底部取消／关闭入口和 `Esc` 仍可使用。保存、安装和更新进行中禁止关闭，避免中断操作。桌面模式下使用宿主提供的标题栏安全间距。删除确认框仍可通过取消按钮或外部区域取消，取消确认不会关闭下层编辑抽屉。

### 提示词注入

每个启用条目注册为独立系统提示词段落，`order: 9200`，在工具说明与交付物引用之后。正文按字面注入，`interpolate: false`，不展开 `{{变量}}` 或 `${...}`。

开启后在后续模型请求的装配中生效；关闭后移除对应段落。面板的「注入中」状态表示当前宿主可注册该条目。

## 实现与安装

- Host：`index.js`，管理本地目录、MCP、提示词和 HTTP RPC。
- 在线来源：`skills-sources.js`，负责来源解析、发现、安装与来源持久化。
- Client：`client.js`，通过统一 `call(action, payload)` 调用宿主，不直接访问文件系统。
- Bundle：`cordis.patch.yml`，注册插件和 MCP 管理 group。

通过 DSH 插件管理器安装当前项目目录。插件替换是否立即生效，以安装结果为准；宿主要求重启时需要重启 DSH，再刷新原有界面。

所有界面请求均走 `POST /dsh-skills-center/rpc`，请求 `{ action, payload }`，返回 `{ ok: true, value }` 或 `{ ok: false, error }`。路由限制为同源 loopback 请求。

Windows 文件发布使用技能扫描目录外的私有暂存区，并校验与技能目录位于同一文件系统。对 `EPERM`、`EBUSY`、`EACCES` 等可能由短暂占用导致的重命名错误做有限重试；已有目标、跨卷及其他错误不会通过覆盖或删除目标绕过。失败恢复也受保护；若备份无法恢复，会保留备份并返回恢复路径，不修改目录权限。

## 验证

```sh
npm test
npm run test:github
npm run test:directory
```

回归测试使用模拟网络与临时目录，覆盖完整安装、来源关联、更新保护、启停恢复、失败处理与并发写入。GitHub 验证脚本访问真实 Cloudflare 仓库，在独立临时 DSH 目录安装、验证并卸载一个技能。skills.sh 验证脚本覆盖真实目录搜索、详情链接解析、单项安装、检查更新、更新和卸载。两种脚本均不修改现有用户技能。

## 限制

- 本地编辑只处理技能主文档，不提供配套资源编辑器。
- 在线来源安装默认写入 DSH 用户技能目录。
- 检查或获取在线更新需要能访问 GitHub；限流和网络错误会显示，已安装技能仍可在本地使用。
- 当前不自动定时更新，不自动安装来源中新出现的技能。
- 通过其他工具安装但没有技能中心来源记录的旧技能，仍按本地技能展示；本版不自动导入其他安装器的锁文件。
- 不自动导入仓库中的 MCP 配置或其他 Agent 的原生插件配置。
- MCP 的参数按空格切分；参数自身包含空格时需要使用支持的写法。
